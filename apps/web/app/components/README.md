# components/

shadcn/ui components live here. `ui/` holds the copied-in shadcn primitives (run `npx shadcn@latest
add <component>`); `mobile/` holds the native-feel shell (bottom tab bar, sheets via Vaul, gesture
wrappers via Motion). Rules: `.claude/rules/frontend.md`, `.claude/rules/pwa-native.md`.

Figure columns use the `tabular` utility (font-variant-numeric: tabular-nums).
