# AGENTS.md

Agent guidance for this repository lives in **[`CLAUDE.md`](CLAUDE.md)** — the single source of
truth — with path-scoped detail in **`.claude/rules/`** (these load when you touch the relevant
code) and the rationale for hard-to-reverse choices in **`docs/decisions/`** (ADRs).

This file exists so tools and agents that read the cross-tool [`AGENTS.md`](https://agents.md)
convention get the same context as Claude Code. **Do not duplicate guidance here** — keep
`CLAUDE.md` canonical and update it instead.
